# 월야의 서약 · RIFT HEROINES 0.9.0

Unity 6000.3.27f1로 만든 여성 캐릭터 중심의 횡스크롤 소환 디펜스 프로토타입입니다. **나루토 6명 + 블리치 6명, 총 12명**입니다. 나루토는 사쿠라·츠나데·히나타·이노·테마리·코난, 블리치는 란기쿠·요루이치·우노하나·루키아·오리히메·소이폰입니다. 공식 소개에서 등장 인물을 확인했으며 출격·영입·적·각성 대장에 같은 명단을 사용합니다. 전원 성인 모습, 8등신 체형과 비키니형 전투 의상을 사용합니다. 홈의 `12명 캐릭터 보기`에서 전원 원화를 볼 수 있습니다.

v0.5.0은 **생존 조합 6쌍 · 월광 제단 쟁탈 · 절묘한 결계 반격 · 무료 각성 보상 · 서약 13종**을 추가했습니다. 원거리 지원 뒤에 근접 병력이 막히는 이동 문제와 치유 중첩 정체를 수정했습니다. 홈의 `전투 가이드`에서 새 규칙을 확인할 수 있습니다. [점검 내용과 반복 실험 결과](Docs/ENGAGEMENT.md).

v0.6.0은 **출격 예약·길게 누르기 · 편성/서약 확인 · 보상 선택 상태 저장 · 누적 도전 6종 · 최근 출정/최고 기록**을 추가했습니다. 저장 백업 복구와 창 전환 일시정지를 보강하고 1600×900·1280×720에서 양 진영을 완주하며 확인했습니다. [편의성 점검 결과](Docs/USABILITY.md).

v0.7.0은 **직접 조작하는 4단계 훈련장 · 바뀌는 대장과 비기 3종 · 구간별 전장 3곳**을 추가했습니다. 홈에서 `직접 배우기 · 훈련`을 누르면 조합·진격·결계 반격·궁극기를 연습합니다. 훈련은 저장된 출정과 누적 보상을 보존합니다. [추가 콘텐츠와 검증](Docs/CONTENT.md).

v0.8.0은 **UI 가독성·입력 상태·타격 시점·음향·전술 차이**를 전체 점검한 버전입니다. 설명 배경·출격 준비 막대·정확한 보스 경고, 경직 중 공격 모션 동기화, 짧고 구분되는 타격 효과·소리를 적용했습니다. [UI·타격감·재미 평가](Docs/EXPERIENCE.md)에 개선 증거와 숙련 편성의 낮은 긴장감을 함께 기록했습니다.

v0.9.0은 **인연 공방**을 추가했습니다. 전투에서 번 조각으로 **특성 24종·출정 부적 3종·별빛 전투 연출 12종·액자 2종**을 영구 해금하고 장착합니다. 원하는 수집 목표를 정해 결과에서 공방으로 이어가며, 준비 변경은 새 출정부터 적용됩니다. [공방 사용법과 검증](Docs/WORKSHOP.md).

## 실행

- iPhone / iPad: [공개 iOS 릴리스](https://github.com/yjmjeminq/rift-heroines-ios/releases)에서 `RiftHeroines-iPhone-unsigned-v0.9.0.ipa`를 내려받아 iLoader로 서명·설치합니다. iOS 15 이상, 가로 화면 전용입니다. 설치된 앱의 이름은 `Rift Heroines`입니다.
- 터치: 카드 탭 / 길게 누르기로 출격, `동료 정보 · 각성`에서 동료 강화, 상단 경계 제목을 탭하면 큰 일시정지 메뉴가 열립니다. 공방은 항목 카드를 탭해 크게 보고 구매하며, 캐릭터 그림을 탭해 12명 중 선택합니다.
- Windows: `게임 실행.cmd` 또는 `Builds/Windows/RiftHeroines.exe`.
- Unity: 이 폴더를 Unity Hub에 추가하고 `Assets/Rift/Scenes/Moonbridge.unity`를 엽니다.
- 재빌드: PowerShell에서 `Tools/build.ps1`. Unity의 `Tools > Rift Heroines > Validate and build Windows`도 사용할 수 있습니다.
- Windows 실행 파일은 같은 폴더의 Data, DLL, MonoBleedingEdge와 함께 보관하세요.

## iOS 빌드

Unity 6000.3.27f1에 iOS Build Support를 설치한 Windows에서 `Tools/export-ios.ps1`로 Xcode 프로젝트를 만듭니다. `Tools/IOSBuild.py prepare`는 내보낸 파일 전체의 SHA256과 게임 데이터 목록을 봉인하고, 공개 GitHub Actions의 Mac / Xcode가 ARM64 실기기 앱을 컴파일합니다. Unity 소스는 이 저장소에, 큰 Xcode 입력 ZIP과 IPA는 Releases에 보관합니다. [자세한 절차와 검증 범위](Docs/IOS.md).

## 전투

| 조작 | 행동 |
|---|---|
| 카드 클릭 / 1–6 | 1회 출격, 자원·준비가 부족하면 1회 예약 |
| 카드 / 1–6 길게 누르기 | 비용과 재사용을 지키며 연속 출격 |
| 같은 예약 카드 / Backspace | 예약 취소 |
| B | 현재 편성·각성·보유 서약 보기, 전투 일시정지 |
| 보상 화면 1–3 / R | 선택 / 무료 새로고침 |
| C / 카드 전환 | 기본 진영 6명과 상대 진영 영입 카드 6명 전환 |
| 카드 아래 각성 | 해당 동료 강화, 기존 병력에도 적용 |
| U / 영맥 | 영력 회복과 최대치 증가 |
| Q / 진격 | 6초 동안 이동·공격 속도 +45% |
| E / 결계 | 영력 30, 5초 동안 아군에게 보호막. 비기 마지막 0.65초면 정밀 반격 |
| R / 궁극기 | 각성 100 소모, 광역 피해·경직·넉백·적 비기 차단 |
| Space / Esc | 일시정지 |
| Tab | 1배 / 2배 |
| F11 | 전체 화면 전환 |

전위는 격투에게, 격투는 술사에게, 술사는 전위에게 강합니다. 유리한 병종에 1.45배 피해를 줍니다. 전위는 받는 피해가 25% 감소합니다. 히나타는 원거리 공격과 짧은 경직, 츠나데와 우노하나는 주변 치유를 담당합니다. 최대 아군 18명, 적군 18명이 전투합니다.

선택한 작품의 6명은 처음부터 전원 출격 가능합니다. 상대 작품의 6명은 구간 보상으로 영입합니다. 카드 페이지를 전환해도 기존 병력과 각성 단계는 유지됩니다. 이전 6인 버전 저장도 인물별 각성 단계를 유지하며 12인 편성으로 변환합니다.

영력은 기본 초당 9씩 회복합니다. 영맥 강화, 생존 조합, 전선 점유, 연속 격파, 서약으로 수급을 늘립니다. 같은 조합의 두 인물이 함께 생존하면 공격력·공속·영력 효과가 켜지며, 복제 병력으로 효과가 중복되지 않습니다. 카드에 마우스를 올리면 짝과 효과가 표시됩니다.

월광 제단은 12초 후 중앙에서 열리고 40초마다 다시 열립니다. 주변 병력으로 쟁탈하며, 아군이 차지하면 영력 +35·각성 +20·12초간 공격력 +20%를 얻습니다. 적도 점령할 수 있습니다.

전장은 1–2경계 월광의 다리, 3–4경계 폭풍의 산문, 5–6경계 백야의 성채로 바뀝니다. 3·6경계의 대장은 상대 진영 여섯 명 중에서 전장 구성에 따라 달라지며 같은 출정 안에서는 서로 다른 인물이 등장합니다. 전열 분쇄는 전열 범위 피해와 밀침, 후열 낙뢰는 후열 범위 피해, 지원 소집은 적 병력 2명 추가입니다. 바닥에 위험 범위·소집 위치를 2.5초 동안 예고합니다. 마지막 0.65초에 금빛 예고가 켜질 때 E를 누르면 비기를 끊고 각성 +15, 대장 2초 경직, 4초간 받는 피해 +35%를 부여합니다. 일찍 누른 결계도 일반 보호막으로 작동하며 R 궁극기로 비기를 끊을 수도 있습니다. 대장을 처치하면 거점의 수호 결계가 사라집니다.

각 경계 돌파 후 **상대 진영 동료 영입·서약·무료 각성** 중 하나를 선택합니다. 보상 위치는 매번 섞이며 다음 적 전술을 미리 표시합니다. 무료 각성은 사용한 동료를 우선 제안합니다. 구간마다 한 번 보상을 무료로 새로 고를 수 있고 다음 전투 시작 시 거점 체력을 30% 회복합니다. 서약 13종에는 5연쇄 폭발·반격 강화·제단 강화가 포함됩니다.

같은 대상에게 적용한 치유는 2초 간격을 두며 대장의 1회 치유량은 최대 체력 3.5%로 제한합니다. 근접 병력은 정지한 원거리 지원을 추월하고 실제 적이 있는 방향으로 이동합니다.

결과의 인연 조각으로 다음 출정의 체력과 시작 영력을 강화합니다. 전투를 중단하면 구간 시작부터 재개하며, 보상 화면에서 종료하면 선택지와 새로고침 사용 상태를 그대로 복원합니다. 출격 예약은 보스 비기 예고 중 자동 지출을 멈춰 결계 영력을 남깁니다. 창 포커스를 잃으면 일시정지하고 1×/2× 배속 설정은 저장합니다.

홈과 결과의 `기록·도전`에서 도전 6종, 12명 출격 도감, 최근 6회 출정과 진영별 최고 시간을 확인합니다. 도전 보상과 출정 보상은 중복 지급되지 않습니다. 결과에서 같은 전장을 다시 선택해 기록에 도전하거나 새로운 전장으로 출정할 수 있습니다. 읽을 수 없는 저장은 손상본을 보존하고 정상 백업에서 복구합니다.

- `Tools/review_workshop.py`, `BuildLogs/workshop-review.json`: 실제 획득 236·소비 230·잔액 6의 대조와 장착/이어하기/정상 속도 전투 검증.
- `RiftFeedback.cs`: 실제 자원·재사용을 반영한 경고와 공격별 타격 표현.
- `RiftExperienceProbe.cs`, `Editor/RiftExperienceAudit.cs`: 일반 속도 프레임·모션 시점·음향 경로 관측과 48개 전략 비교.
- `Editor/RiftValidation.cs`: 양 진영 캠페인, 소환 비용·제한, 보상, 저장·복원 검증.
- `Editor/RiftTacticsValidation.cs`, `RiftPlaytest.cs`: 새 전술의 실제 효과·이동 회귀 검사와 5개 조작 정책 × 8회, 총 40회 전투 실험.
- `Tools/smoke.ps1`: 실제 실행 파일에서 시작 버튼, 출격, 일시정지, 보상, 완주, 상대 진영, 이어하기 및 스크린샷 검증. 별도 프로필을 사용합니다.
- `BuildLogs/model-validation.json`, `build-result.json`, `PlayerSmoke/report.json`: 실제 검증 결과.
- `Tools/validate_roster.py`, `BuildLogs/roster-audit.json`: 전체 명단·이미지·프롬프트·실행 데이터 일치와 이전 인물 잔존 검사.
- `Tools/review_engagement.py`, `BuildLogs/engagement-review.json`: 기존 조작 정책을 유지한 전후 비교와 새 규칙의 모델·실행본 증거를 대조합니다.
- `Tools/review_experience.py`, `BuildLogs/experience-review.json`: 두 해상도 UI·일반 속도 연출·음향·전략의 증거와 평가. `Tools/experience.ps1 -OutputFolder ExperienceV090`로 일반 속도 관찰을 실행하며 `Tools/experience_media.py`로 미리보기를 만듭니다.
- `Tools/review_content.py`, `BuildLogs/content-review.json`: 훈련 네 단계·저장 보존·열두 대장 후보·세 비기·세 배경과 신규 원화 원본 일치 검증.
- `Tools/review_usability.py`, `BuildLogs/usability-review.json`: 보상 복원·예약·길게 누르기·진행 기록·두 해상도 검증을 대조합니다. 작은 해상도 검증은 `Tools/smoke.ps1 -Width 1280 -Height 720 -OutputFolder PlayerSmoke1280`으로 실행합니다.

현재 범위는 단독 플레이 Windows 프로토타입입니다. 터치 가능한 UI를 사용하며 모바일 플랫폼 빌드와 실제 기기 검증은 후속 범위입니다.
